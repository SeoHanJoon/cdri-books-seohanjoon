# 0024. 아이콘 컴포넌트는 크기(sm/lg)만 받고 색은 안에서 정한다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 2

## 배경
[0017](0017-icons-react-components.md)에서 아이콘을 React 컴포넌트로 쓰기로 했다. 시안에는 같은 모양이 크기·색만 바꿔 여러 곳에 쓰인다.
- 하트: 큰 채움 24px(펼친 행), 작은 채움 16px(접힌 행), 큰 테두리 24px, 작은 테두리 16px
- 화살표: 상세검색 팝업 Select 10.5×6, 상세보기 버튼 14×8 (같은 비율)
- 닫기 X: 팝업 11.67(회색), 검색 기록 16(검정) (같은 비율)

Figma API 한도 초과로 일부 크기만 SVG로 받았다. 받은 SVG를 키우거나 줄여 쓸 때 원본과의 차이는 비교 페이지로 확인했다. (작은 채움 하트는 1px 안팎)

## 선택지
- A안 크기·색을 모두 쓰는 쪽에서 정함(`className`): 유연함 / 쓸 때마다 색 클래스를 기억해야 함
- B안 아이콘마다 컴포넌트 하나, `size: 'sm' | 'lg'`만 받고 색은 컴포넌트 안에서 정함: 쓰는 쪽이 단순 / 시안에 없는 조합은 만들 수 없음

## 결정
B안 (사용자 선택). 쓰는 쪽이 색을 몰라도 되게 한다.
- `HeartIcon { filled, size }`: 채움은 빨강(`red`), 테두리는 회색(`gray`). 작은 테두리 하트는 시안에서 흰색이지만, 모양을 "빨간 채움 / 회색 테두리" 2가지로 단순하게 유지하려고 회색으로 통일한다.
- `ChevronIcon { size, direction }`, `CloseIcon { size }`, `SearchIcon`
- 작은 채움 하트는 24px 하트를 그대로 줄이지 않는다. 24px 하트에는 2px 테두리가 있어 그대로 줄이면 원본보다 2px 커진다. 테두리를 빼고 Figma 원본 크기(16px 안 13.33×12.23)에 맞춘다.

## 결과
- 아이콘 사용이 `<HeartIcon filled={liked} size="sm" />` 한 줄로 끝난다.
- 작은 테두리 하트는 시안(흰색)과 다르다. 밝은 표지 위에서는 덜 보일 수 있다.
- 새 크기나 색이 필요하면 컴포넌트에 변형을 추가해야 한다.
