# 0024. 아이콘 컴포넌트는 크기만 받고 색은 안에서 정한다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 2

## 배경
[0017](0017-icons-react-components.md)에서 아이콘을 React 컴포넌트로 쓰기로 했다. 시안에는 같은 모양이 크기·색만 바꿔 여러 곳에 쓰인다.
- 하트: 큰 채움 24px(펼친 행), 작은 채움 16px(접힌 행), 큰 테두리 24px, 작은 테두리 16px
- 화살표: 상세검색 팝업 Select 10.5×6, 상세보기 버튼 14×8 (같은 비율)
- 닫기 X: 팝업 11.67(회색), 검색 기록 16(검정) (같은 비율)

Figma API 한도 초과로 일부 크기만 SVG로 받았다. 받은 SVG를 키우거나 줄여 쓸 때 원본과의 차이는 비교 페이지로 확인했다. (작은 채움 하트는 1px 안팎)

## 선택지
- A안 크기·색을 모두 쓰는 쪽에서 정함(`className`): 유연함 / 쓸 때마다 색 클래스를 기억해야 함
- B안 아이콘마다 컴포넌트 하나, 크기만 받고 색은 컴포넌트 안에서 정함: 쓰는 쪽이 단순 / 시안에 없는 조합은 만들 수 없음

## 결정
B안 (사용자 선택). 쓰는 쪽이 색을 몰라도 되게 한다.
- `HeartIcon { filled, size: 16 | 24 }`: 채움은 빨강(`red`), 테두리는 회색(`gray`). 작은 테두리 하트는 시안에서 흰색이지만, 모양을 "빨간 채움 / 회색 테두리" 2가지로 단순하게 유지하려고 회색으로 통일한다.
- `CloseIcon { size: 20 | 24, className }`: 닫기 X는 놓이는 곳(팝업 회색, 검색 기록 검정)마다 색이 달라 예외로 색을 `className`으로 받는다. 기본값은 받은 원본 SVG의 색인 `text-ui-gray`.
- `ChevronIcon { size: 20 | 24, direction }`, `SearchIcon`
- 받은 SVG를 다른 크기로 쓸 때는 viewBox를 그대로 두고 `width`/`height`만 바꾼다. 도형 위치·크기를 계산으로 맞추는 방법도 검토했지만, 코드가 복잡해지는 것에 비해 차이가 1~2px라서 쓰지 않는다.
  - 작은 하트: 세로가 원본보다 약 0.8px 작다. 채움 하트는 24px에 있는 2px 테두리를 16px에서는 뺀다. 그대로 두면 원본보다 2px 커진다.
  - 검색 기록 X: 원본 16px보다 2px 작은 14px가 된다.
  - 상세보기 화살표: 원본 14×8보다 작은 약 12.6×7.2가 된다.

## 결과
- 아이콘 사용이 `<HeartIcon filled={liked} size={16} />` 한 줄로 끝난다.
- 작은 테두리 하트는 시안(흰색)과 다르다. 밝은 표지 위에서는 덜 보일 수 있다.
- 새 크기나 색이 필요하면 컴포넌트에 변형을 추가해야 한다.
