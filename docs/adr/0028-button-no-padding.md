# 0028. Button은 좌우 여백 없이 내용을 가운데에 두고, 너비는 쓰는 쪽에서 정한다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 2

## 배경
시안의 버튼은 모두 너비가 정해져 있다: 구매하기·상세보기 115px, 펼친 행 구매하기 240px, 상세검색 72px.
처음에는 변형마다 좌우 여백(`px-5`, `px-2.5`)을 두었는데, 상세보기 버튼은 글자(59px)와 화살표 아이콘 상자(24px)가 115px − 여백 40px = 75px에 들어가지 않아 아이콘이 찌그러졌다. 이를 바깥에서 `pr-2.5`로 덮어쓰면 [0025](0025-clsx.md)에서 정한 "`className`은 너비·배치용만" 규칙을 어긴다.

## 선택지
- A안 변형별 여백 유지 + 바깥에서 덮어쓰기: 상세보기가 시안과 1px 이내 / 내부 클래스 덮어쓰기, CSS 순서에 기댐
- B안 여백을 없애고 가운데 정렬, 너비는 쓰는 쪽에서: 덮어쓰기 없음 / 너비를 안 주면 글자가 테두리에 붙음, 상세보기 내용이 시안보다 4px 왼쪽

## 결정
B안 (사용자 선택). 변형은 높이·글자·색만 정하고, 너비는 `className`으로 정한다.
상세보기의 4px 차이는 아이콘 SVG의 상자 여백 때문이라, 아이콘 SVG를 통일할 때 함께 해결한다. ([PLAN](../PLAN.md) Step 9)

## 결과
- Button을 쓸 때는 항상 너비를 준다.
- 글자만 있는 버튼은 시안과 같다.
- 버튼 글자는 줄바꿈하지 않는다(`whitespace-nowrap`). 한글은 글자 사이 어디서든 줄이 바뀌어, 공간이 모자라면 두 줄로 꺾이기 때문이다.
