# 0018. Button은 href가 있으면 링크(<a>), 없으면 버튼(<button>)으로 그린다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 2

## 배경
버튼 모양은 3가지다: 구매하기(primary), 상세보기(secondary), 상세검색(outline).
그중 구매하기는 책 상세 페이지를 새 탭으로 여는 링크라서, 의미상 `<a>`가 맞다.

## 선택지
- A안 `variant` + 스타일 함수: `<button>` 컴포넌트와 `buttonStyles()` 함수를 따로 둠 / 쓰는 곳에서 두 방식을 구분해야 함
- B안 `as` prop: 하나로 두 태그 / props 타입이 복잡함
- C안 모두 `<button>` + `window.open`: 단순 / 우클릭 새 탭, 스크린리더의 링크 안내를 잃음
- D안 `href` 유무로 분기: 컴포넌트 하나, 쓰는 곳은 `href`만 넘기면 됨 / props 타입을 두 갈래로 나눠야 함

## 결정
D안 (사용자 제안). 쓰는 쪽에서는 `<Button href={url} target="_blank">`처럼 자연스럽게 쓴다.
props 타입은 판별 유니온으로 나눈다. `href`가 있으면 `<a>` 속성만, 없으면 `<button>` 속성만 받는다. (판별 유니온: 특정 값의 유무로 어느 타입인지 TypeScript가 구분하는 방식)

## 결과
- 링크는 링크로, 버튼은 버튼으로 렌더링되어 브라우저 기본 기능과 접근성이 유지된다.
- `<a>`에 `disabled`를 넘기는 실수는 타입 검사에서 걸린다.
