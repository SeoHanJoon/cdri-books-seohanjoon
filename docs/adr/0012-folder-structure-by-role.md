# 0012. src/ 폴더는 역할별로 나눈다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 1 이후 전체

## 배경
화면은 도서 검색, 내가 찜한 책 두 페이지이고, 기능은 검색·검색 기록·상세 검색·찜하기다.
`BookListItem`처럼 두 페이지가 함께 쓰는 컴포넌트가 있다.

## 선택지
- A안 역할별 (`app/`, `pages/`, `components/`, `hooks/`, `api/`, `stores/`, `lib/`, `mocks/`, `styles/`): 가장 흔하고 단순, 어디에 둘지 고민이 적음 / 기능 하나를 고치면 여러 폴더를 오가야 함
- B안 기능별 (`features/search`, `features/wishlist` …, `shared/`): 기능 PR이 폴더 하나에서 끝남 / 공용과 기능 중 어디에 둘지 판단이 가끔 필요

## 결정
A안. 페이지 2개 규모에서는 폴더 수가 적고 익숙한 구조가 읽기 쉽다.

## 결과
- 평가자가 처음 보는 저장소에서도 파일 위치를 바로 짐작할 수 있다.
- 기능이 많아져 한 폴더에 파일이 몰리면 그때 기능별로 묶는 것을 검토한다.
