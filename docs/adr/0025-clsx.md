# 0025. 클래스 이름 합치기는 clsx로 한다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 2 이후 전체

## 배경
Button은 기본 클래스, 변형(`variant`)별 클래스, 바깥에서 넘긴 `className`을 합친다. 처음에는 배열을 `filter(Boolean).join(' ')`하는 보조 함수를 직접 만들었는데, 컴포넌트마다 이런 함수가 생기면 코드가 늘어난다.
앞으로 헤더 활성 탭, 펼친 행, 찜 여부처럼 조건에 따라 클래스를 붙이는 곳이 계속 생긴다.

## 선택지
- A안 clsx: 조건부 클래스를 합치는 표준적인 작은 라이브러리(압축 약 0.2KB) / 의존성 1개 추가
- B안 clsx + tailwind-merge: 충돌하는 Tailwind 클래스(예: `px-5`와 `px-8`)를 뒤의 것만 남김 / 약 7KB, 커스텀 글자 토큰(`text-caption`)을 글자색(`text-white`)과 같은 종류로 보고 지워버려 별도 설정이 필요
- C안 라이브러리 없이 템플릿 문자열: 의존성 없음 / 조건이 여러 개면 읽기 어려움

## 결정
A안. 바깥에서 넘기는 `className`은 너비·배치용으로만 쓰고 컴포넌트 내부 클래스와 겹치지 않게 하므로, 충돌 해결(tailwind-merge)까지는 필요 없다.
버전은 2.1.1 (2024-04 배포, [0015](0015-pnpm-minimum-release-age.md)의 최소 배포 기간 충족).

## 결과
- 조건부 클래스를 `clsx('text-ui-gray', isUp && 'rotate-180')`처럼 한 가지 방식으로 쓴다.
- `className`으로 내부 클래스를 덮어쓰려 하면 둘 다 붙어 결과가 CSS 순서에 따라 달라진다. 그런 경우가 생기면 변형(`variant`)을 추가한다.
