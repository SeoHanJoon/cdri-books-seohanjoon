# 0002. 스타일링은 Tailwind CSS v4 + Figma 토큰으로 한다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 1, Step 2

## 배경
Figma에 스타일 가이드(색상 9개, 타이포그래피 8개)가 정의되어 있고, 구현은 이 가이드를 따라야 한다.
간격·radius·shadow는 가이드에 없어 화면 시안 실측값으로 보완해야 한다.

## 선택지
- A안 Tailwind v4: `@theme`에 토큰을 CSS 변수로 정의하면 `bg-primary`, `text-title1` 같은 클래스가 생김. 기본 팔레트를 지워 가이드 밖 색을 막을 수 있음 / 클래스가 길어질 수 있음
- B안 CSS Modules + CSS 변수: 표준 CSS, 러닝커브 없음 / 토큰 강제 수단이 없어 임의 값이 섞이기 쉬움
- C안 CSS-in-JS (Emotion 등): 컴포넌트와 스타일이 한 파일 / 런타임 비용, React 19·서버 렌더링 호환 이슈 이력

## 결정
A안. Figma 토큰을 `@theme` 한 곳에 옮기고 기본 팔레트(`--color-*: initial`)를 제거해, 가이드에 없는 색은 클래스 자체가 없도록 한다.
`text-[#353C49]` 같은 임의 값 사용은 프로젝트 규칙으로 금지한다.

## 결과
- 디자인이 바뀌면 `@theme` 파일만 고치면 된다.
- 토큰 이름이 Figma 스타일 이름과 같아 디자인과 코드를 대조하기 쉽다.
- 가이드의 행간이 대부분 100%라 여러 줄 텍스트(책 소개)는 시안 실측값을 따로 확인해야 한다.
