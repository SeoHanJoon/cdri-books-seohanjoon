# 0023. 모바일 화면 너비까지 대응한다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 2 이후 전체

## 배경
Figma 시안은 1920px 데스크톱 화면 하나뿐이다. 본문 폭은 960px, 헤더 로고의 왼쪽 여백은 160px이다.

## 선택지
- A안 데스크톱 기준: 시안 그대로 / 960px보다 좁으면 가로 스크롤
- B안 모바일까지: 어떤 기기에서도 사용 가능 / 시안이 없어 배치를 직접 설계해야 하고 작업 범위가 커짐

## 결정
B안. 넓은 화면은 시안과 똑같이 구현하고, 좁은 화면에서는 배치를 바꾼다.
모바일 배치는 시안이 없으므로 배치가 바뀌는 컴포넌트(헤더, 책 행 등)를 만들 때마다 추천안을 보여주고 확인받은 뒤 구현한다.

## 결과
- 평가자가 어떤 창 크기로 열어도 화면이 깨지지 않는다.
- 컴포넌트마다 좁은 화면 배치를 확인하는 작업이 늘어난다. Playwright에 모바일 viewport 확인을 추가한다.
