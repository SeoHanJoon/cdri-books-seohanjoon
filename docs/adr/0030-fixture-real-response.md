# 0030. fixture는 실제 카카오 응답을 저장하고, 화면 단계에서는 검색어로 고른다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 3, Step 5

## 배경
화면 단계(Step 3~4)는 API 없이 카카오 응답 형식의 fixture로 화면을 만든다. ([0009](0009-screens-first-msw.md))
fixture를 어떻게 마련할지, API 없이 초기 / 결과 / 결과 없음 세 상태를 어떻게 오갈지 정해야 한다.

## 선택지
- fixture 마련
  - A안 실제 API 응답 저장: 빈 isbn, `sale_price: -1`, 잘린 책 소개 같은 실제 형식을 그대로 담음, 시안과 같은 책 / `.env` 키 필요, 표지를 카카오 서버에서 불러옴
  - B안 손으로 작성: 키 불필요 / 실제 응답과 미묘하게 달라질 수 있음, 표지를 따로 만들어야 함
- 상태 전환
  - A안 제출한 검색어로 fixture 선택: 빈 검색어 → 초기, fixture에 있는 검색어 → 결과, 그 외 → 결과 없음 / 임시 함수 하나 필요
  - B안 검색하면 항상 결과: 단순 / 결과 없음 화면을 페이지에서 볼 수 없음

## 결정
둘 다 A안. (사용자 선택)
fixture는 "무라카미 하루키" 검색 응답(결과 있음)과 0건 응답(결과 없음)이다. 키 값은 fixture에 들어가지 않는다.
검색어로 fixture를 고르는 함수는 Step 5에서 `useInfiniteQuery`로 바뀌고, fixture는 MSW handler가 그대로 쓴다.

## 결과
- 세 상태를 실제 페이지와 PR 영상에서 모두 보여줄 수 있다.
- 변환 함수가 실제 응답의 예외 값으로 처음부터 테스트된다.
- 표지 이미지는 외부(카카오 CDN)에서 불러오므로, 네트워크가 없으면 테스트 화면에 표지가 빈다. 화면 검사는 표지에 의존하지 않게 쓴다.
