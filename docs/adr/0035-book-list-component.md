# 0035. 책 목록과 펼침 상태는 BookList 컴포넌트가 맡는다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 3, Step 4, Step 8

## 배경
도서 검색 페이지(Step 3)와 내가 찜한 책 페이지(Step 4)는 같은 책 목록을 쓰고, 두 곳 모두 여러 권을 동시에 펼칠 수 있다.
펼침 여부는 화면 안에서만 쓰는 상태이고, 찜 여부는 Step 8에서 store와 연결된다.

## 선택지
- A안 `BookList` 컴포넌트(`books`, `isLiked`, `onToggleLike`)가 펼침 상태를 내부에 둠: 두 페이지가 그대로 재사용, 검색어가 바뀌면 `key`로 펼침 초기화 / 컴포넌트 하나 증가
- B안 각 페이지가 펼침 `Set`을 갖고 `BookListItem`을 직접 그림: 컴포넌트 수 그대로 / 같은 코드가 두 페이지에 중복

## 결정
A안. (사용자 선택)
찜은 Step 8 전까지 연결하지 않으므로, 페이지는 "항상 찜 안 함"과 "눌러도 아무 일 없음"을 넘긴다. ([0032](0032-book-list-item-single-component.md))

## 결과
- 찜 연결(Step 8)은 페이지가 넘기는 `isLiked`, `onToggleLike`만 바꾸면 된다.
- 새로 검색하면 이전 검색에서 펼친 행이 남지 않는다.
