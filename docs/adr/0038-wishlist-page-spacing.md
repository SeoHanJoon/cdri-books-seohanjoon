# 0038. 내가 찜한 책 페이지의 세로 간격은 도서 검색 페이지와 맞춘다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 4

## 배경
찜 시안(`757:1435`, `744:313`)과 도서 검색 시안의 세로 간격이 조금씩 다르다.

| 간격 | 찜 시안 | 도서 검색 (구현, [0037](0037-search-page-layout-and-contents.md)) |
|---|---|---|
| 헤더 → 제목 | 80px | 104px (768px 미만 40px) |
| 건수 → 목록 | 36px | 32px |
| 건수 → 빈 상태 | 117px | 120px |

찜 시안의 첫 행은 본문 상자(x=480)보다 4px 왼쪽(x=476)에 있어, 시안 안에서도 배치가 정확히 맞지 않는다.

## 선택지
- A안 도서 검색과 맞춤: 탭을 오가도 제목·목록 위치가 그대로 / 찜 시안과 최대 24px 다름
- B안 찜 시안 그대로: 시안과 1:1 / 탭을 바꿀 때 제목이 24px 위아래로 움직임, 좁은 화면 여백을 따로 정해야 함

## 결정
A안. (사용자 선택)
두 페이지는 같은 앱의 같은 본문 자리이고, 차이는 시안 배치 실수로 본다. 0037에서 도서 검색 초기 화면의 36px 어긋남을 같은 이유로 맞췄다.

## 결과
- 두 탭을 오갈 때 제목, 건수, 목록의 시작 위치가 같다.
- 찜 시안과 비교하면 제목이 24px 아래에 있다.
