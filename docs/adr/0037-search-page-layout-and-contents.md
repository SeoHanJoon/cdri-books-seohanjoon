# 0037. 도서 검색 화면 배치와 잘린 책 소개 표시 (디자인 미명시)

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 3

## 배경
Step 3에서 도서 검색 화면을 시안과 맞추다 보니 시안이 정하지 않았거나 서로 다른 부분이 세 가지 나왔다.
1. 본문 가로 위치: 초기 화면(`18:969`)은 본문이 가운데에서 36px 오른쪽(x=516)이고, 결과 화면(`18:805`)은 가운데(x=480)다.
2. 좁은 화면의 위쪽 여백: 시안의 헤더 아래 104px를 375px에서도 쓰면 위쪽이 지나치게 넓다. ([0023](0023-responsive-mobile.md))
3. 책 소개 끝: 카카오는 책 소개를 250자 안팎에서 문장 중간에 자른다(fixture 10권 모두 252~256자). 그대로 보여주면 글이 끊긴 것인지 끝난 것인지 알 수 없다.

## 선택지
- 1: A안 가운데 유지 / B안 초기 화면만 36px 오른쪽(검색하면 본문이 옆으로 점프)
- 2: A안 768px 미만은 40px / B안 모든 너비 104px
- 3: A안 문장 끝 부호로 끝나지 않으면 "…" 붙임 / B안 항상 붙임(원래 짧은 소개에도 붙음) / C안 그대로 둠

## 결정
모두 A안. (사용자 선택)
1. 결과 화면과 헤더 탭(가운데 정렬)에 맞춘다. 초기 화면의 36px는 시안 배치 실수로 본다.
2. 헤더가 한 줄이 되는 768px부터 시안의 104px, 그보다 좁으면 40px.
3. `.` `!` `?` `”` `』` 같은 문장 끝 부호로 끝나지 않으면 잘린 것으로 보고 "…"를 붙인다. 카카오 데이터의 규칙이므로 변환 함수 `toBook`에 둔다. ([0019](0019-book-view-type.md))

## 결과
- 검색 전후로 본문 위치가 바뀌지 않는다.
- 우연히 문장 끝 부호에서 잘린 소개에는 "…"가 붙지 않는다. 이 경우는 드물어서 감수한다.
- 찜 스냅샷(Step 8)에도 "…"가 붙은 소개가 저장된다.
