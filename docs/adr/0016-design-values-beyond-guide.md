# 0016. 스타일 가이드에 없는 시안 값은 토큰으로 추가한다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 2

## 배경
Figma 스타일 가이드(`753:96`)에는 색 9개, 글자 스타일 8개만 있다. 그런데 Elements(`754:70`)와 화면 시안에는 가이드에 없는 값이 쓰였다.
- 색: `#1A1E27` 페이지 제목(Figma 스타일 `Text/Title`), `#B1B8C0` 상세보기 화살표(`UI/Gray`), `#D2D6DA` 행 구분선(스타일 없음)
- 글자: 원가 굵기 350, "총 N건" 굵기 400, 책 소개 본문 행간 16px, 펼친 행 제목·가격 행간 26px, 건수 문구 행간 24px

## 선택지
- A안 토큰 추가: 시안과 똑같이 구현됨 / 토큰 수가 늘어남
- B안 가장 가까운 기존 토큰으로 대체: 가이드 그대로 유지 / 시안과 미세하게 다름 (회색 2개 → `#DADADA`, 350 → 400 등)

## 결정
A안. UI 완성도가 첫 번째 평가 항목이고, 프로젝트 규칙도 "토큰에 없는 값은 Figma 실측 후 토큰으로 추가"다.
- 색 2개는 `@theme`에 추가한다: `ui-gray`(Figma 스타일 이름을 따름), `divider`
- 페이지 제목 색 `#1A1E27`은 추가하지 않고 가이드의 `Text/Primary`(#353C49)를 쓴다. 클래스 이름 `text-text-title`이 글자 크기 토큰 `text-title2`와 헷갈리고, 두 색의 차이가 작아 가이드 안의 색으로 통일한다. (사용자 결정)
- 굵기 350은 `--font-weight-demilight`로 추가한다 (Noto Sans KR의 DemiLight 굵기)
- 행간과 굵기 400은 Tailwind 기본 클래스(`leading-4`, `leading-6`, `font-normal`)로 맞춘다. `text-[14px]` 같은 임의 값은 계속 쓰지 않는다.

## 결과
- 시안과 화면을 1:1로 비교할 수 있다.
- 가이드 밖 값도 `@theme` 한 곳에 모여 있어, 디자인이 바뀌면 그 파일만 고치면 된다.
- 찜 화면(`744:313`)의 헤더 인스턴스는 `#000` 같은 옛 색을 쓰는 구버전 컴포넌트라서 따르지 않는다. 기준은 Elements의 Header다.
