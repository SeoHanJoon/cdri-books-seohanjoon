# 0004. 검색 기록에는 전체 검색만 저장한다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 6, Step 7

## 배경
Figma는 검색 기록(최대 8개, 오래된 것부터 삭제, 재시작 후 유지)을 전체 검색창 아래 드롭다운으로 보여준다.
상세 검색(제목/저자명/출판사 조건)도 기록에 남길지는 명시되어 있지 않다.

## 선택지
- A안 전체 검색만 저장: 기록을 누르면 항상 전체 검색으로 다시 실행되어 동작이 명확 / 상세 검색어는 다시 입력해야 함
- B안 상세 검색도 저장: 모든 검색을 다시 쓸 수 있음 / 기록에 조건(제목/저자명/출판사)까지 표시해야 하고, 누를 때 전체 검색인지 상세 검색인지 사용자가 헷갈림. 시안의 기록 항목에는 조건 표시가 없음

## 결정
A안. 기록 드롭다운이 전체 검색창에 붙어 있고, 시안의 기록 항목은 검색어만 보여준다.
또 Figma는 "전체 검색과 상세 검색은 동시에 진행 불가"라고 해서 두 검색을 분리된 흐름으로 다룬다. 기록도 전체 검색 흐름에만 속하게 했다.

## 결과
- 기록 데이터는 문자열 배열로 단순하다.
- 상세 검색을 자주 반복하는 사용자는 조건을 다시 입력해야 한다.
