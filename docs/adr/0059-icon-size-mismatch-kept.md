# 0059. 아이콘의 1~4px 어긋남은 시안에 맞추지 않는다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 9

## 배경
[0024](0024-icon-component-props.md)에서 받은 SVG는 viewBox를 그대로 두고 `width`/`height`만 바꿔 쓰기로 했다. 원본 상자가 제각각이라 다른 크기로 쓰는 곳에서 시안과 어긋난다.
- 상세보기 화살표: 12.6×7.2 (시안 14×8)
- 검색 기록 X: 14px (시안 16px)
- 상세보기 버튼 안 글자·화살표 묶음: 시안보다 4px 왼쪽

Step 2에서 "크기별 원본을 다시 받아 맞춘다"를 Step 9 할 일로 남겼다. 지금은 Figma REST API가 요청 한도로 약 4.2일 막혀 있다(429).

## 선택지
- A안 Figma 앱에서 크기별 SVG를 직접 복사해 다시 옮김: 시안과 정확히 같음 / 수작업
- B안 실측값으로 크기별 viewBox를 계산: Figma 불필요 / 0024에서 복잡도 때문에 뺀 방법, 4px는 근거 없이 맞추게 됨
- C안 맞추지 않음: 0024 그대로 / 1~4px 차이가 남음

## 결정
C안. (사용자 선택)
차이가 1~4px로 눈에 잘 띄지 않고, 0024의 단순한 아이콘 사용 방식(`size`만 받음)을 유지한다.

## 결과
- 아이콘 코드는 바뀌지 않는다.
- 위 세 곳은 시안과 1~4px 다르다. README에 알려진 차이로 적는다.
