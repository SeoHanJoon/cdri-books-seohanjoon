# 0041. 존재하지 않는 페이지는 NoData 없이 제목과 버튼만 보여준다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 4, Step 5

## 배경
Step 4에서 존재하지 않는 페이지를 0010대로 `NoData`(책 아이콘 + 문구)와 돌아가기 버튼으로 만들었다. ([0010](0010-not-found.md))
화면을 보니 책 아이콘이 어색했다. `NoData`의 책 아이콘은 "검색된 결과가 없습니다", "찜한 책이 없습니다"처럼 책이 비어 있다는 뜻인데, 주소가 잘못된 상황과는 맞지 않는다.

## 선택지
- A안 NotFound가 제목(h1)과 버튼을 직접 그림: `NoData`는 "데이터 없음" 전용으로 남고 props 그대로, 문구가 제목이라 스크린리더가 페이지 주제를 앎 / 0010의 "`NoData` 재사용"과 달라짐
- B안 `NoData`에 아이콘을 끄는 prop 추가: 문구 모양 유지 / `NoData` 공개 인터페이스가 늘어남
- C안 아이콘 자리에 큰 "404": 흔한 패턴 / 시안에 없는 글자 크기라 근거 없는 토큰이 생김

## 결정
A안. (사용자 선택)
문구는 페이지 제목과 같은 `Title2`로 가운데에 두고, 그 아래 32px에 "도서 검색으로 돌아가기" 버튼을 둔다. 위쪽 여백은 다른 페이지와 같다.

## 결과
- 책이 없다는 화면과 주소가 잘못됐다는 화면이 그림으로 구별된다.
- Step 5에서 잘못된 `target`이 들어오면 도서 검색 페이지가 이 화면을 그대로 그린다.
- Header, 문구, 돌아가기 버튼은 0010 그대로다. 바뀐 것은 `NoData`를 쓰지 않는다는 점뿐이다.
