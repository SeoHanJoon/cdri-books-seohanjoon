# 0013. Noto Sans KR은 @fontsource-variable로 자체 호스팅한다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 1

## 배경
Figma 스타일 가이드는 Noto Sans KR 500·700만 쓴다. 한글 폰트는 글자 수가 많아 파일이 크다.
처음에는 전체 폰트 파일을 직접 추가하기로 했다가, 실제 크기를 재 보고 다시 골랐다.
측정 기준은 화면 고정 문구와 책 제목 10여 개가 있는 예시 화면이다.

## 선택지
- A안 전체 파일 직접 추가: 파일 2개로 단순, 의존성 없음 / TTF 12.4MB, woff2로 바꿔도 4.2MB를 첫 방문에 받음
- B안 Google Fonts `<link>` (가변 폰트): 글자 범위별 조각 124개 중 화면에 쓰인 것만 받아 약 200KB / 외부 서버 의존, 네트워크가 없으면 e2e·PR 영상의 폰트가 달라짐
- C안 `@fontsource-variable/noto-sans-kr`: B안과 같은 조각 파일을 npm 패키지로 포함해 약 200KB / 의존성 1개, 빌드 결과물에 조각 파일 124개

## 결정
C안. 첫 방문에 받는 양이 A안의 약 1/20이고, 외부 서버 없이도 테스트와 영상에서 항상 같은 폰트가 나온다.
가변 폰트(굵기 100~900이 한 파일에 든 폰트)라 500과 700을 따로 받지 않는다.

## 결과
- 예시 화면에서는 124개 조각 중 3~12개만 받는다. 검색 결과에 새 글자가 나오면 그 조각만 더 받는다.
- 조각 124개의 `@font-face` 선언 때문에 CSS가 85KB(gzip 28KB)다. Step 9에서 쓰지 않는 문자 집합(키릴, 베트남어)을 빼는 것을 검토한다.
- 폰트는 SIL Open Font License 1.1이고, 라이선스 문서는 패키지에 포함되어 있다.
