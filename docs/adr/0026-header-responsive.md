# 0026. Header는 너비 3단계로 배치하고 탭은 항상 가운데에 둔다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 2

## 배경
시안(1920px)에서 로고는 왼쪽 160px, 탭은 화면 가운데에서 왼쪽으로 193px 위치에서 시작한다. 이 배치를 그대로 두면 1024px쯤에서 로고와 탭이 겹친다.
모바일까지 대응하기로 했으므로([0023](0023-responsive-mobile.md)) 좁은 화면 배치를 정해야 한다.

## 선택지
- A안 3단계, 넓은 화면은 시안 그대로: 1920px에서 시안과 같음 / 너비마다 탭 위치 규칙이 달라짐
- B안 탭을 항상 화면 가운데에: 규칙이 단순 / 1920px에서 탭이 시안보다 75px 오른쪽
- C안 모바일도 한 줄, 글자 축소: 헤더가 낮음 / 360px 화면에서 여백이 거의 없음

## 결정
A안의 3단계에 B안의 "탭은 항상 가운데"를 합친다. (사용자 선택)
- 1280px 이상: 로고 왼쪽 160px, 탭 가운데
- 768~1279px: 한 줄, 로고 왼쪽 24px, 탭 가운데
- 768px 미만: 두 줄, 위에 로고, 아래에 탭

함께 정한 것
- 탭 클릭 영역: 탭 사이 간격(56px)을 각 링크의 좌우 여백(28px)으로 옮기고, 링크 높이를 줄 높이만큼 채워 빈 곳 없이 누를 수 있게 한다.
- 로고는 도서 검색(`/`)으로 가는 링크다. (시안 미명시, 흔한 동작)

## 결과
- 1920px에서 탭이 시안보다 75px 오른쪽에 있다.
- 로고와 탭이 어떤 너비에서도 겹치지 않는 것을 브라우저 테스트(375 / 768 / 1024px)로 지킨다.
