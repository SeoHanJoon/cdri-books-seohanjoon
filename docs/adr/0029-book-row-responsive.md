# 0029. 책 행은 1024px 미만에서 세로로 쌓는다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 2

## 배경
시안의 접힌 행은 표지·제목·저자·가격·버튼 2개가 960px 한 줄에, 펼친 행은 표지(210px)·책 소개(360px)·가격·구매하기(240px)가 가로로 놓인다. 고정 너비 요소가 많아 좁은 화면에 들어가지 않는다. ([0023](0023-responsive-mobile.md))

## 선택지
- A안 세로로 쌓기: 접힌 행은 표지 옆에 제목·저자·가격을 쌓고 버튼 2개를 그 아래에, 펼친 행은 표지 → 제목 → 책 소개 → 가격 → 구매하기 순서 / 행이 길어짐
- B안 접힌 행 단순화: 접힌 행에서 구매하기를 빼고 화살표만 / 모바일에서 구매까지 한 번 더 눌러야 함

## 결정
A안 (사용자 선택). 1024px 이상은 시안 그대로, 미만은 세로로 쌓는다. 시안의 모든 요소가 그대로 남는다.
접힌 행의 구매하기·상세보기는 1024px 미만에서 표지 아래 줄에 행 전체 너비를 반씩 나눠 크게 둔다. 시안 크기(115px)를 그대로 두면 모바일에서 버튼이 작고 오른쪽에 빈 공간이 남기 때문이다.

함께 정한 것 (시안 미명시)
- 할인가가 없으면 원가 한 줄만 할인가 자리(구매하기 위)에 굵게(700) 표시한다. 실제로 내는 가격이라 할인가와 같은 스타일로 둔다. ([0021](0021-price-and-heart-behavior.md))
- 표지가 없으면(`thumbnail` 빈 값) `ui-gray`(#B1B8C0) 상자를 보여준다. 더 진한 `text-secondary`(#6D7582), `text-subtitle`(#8D94A0)도 비교했지만 표지 자리로는 너무 진했다. 이 배경에서 찜 안 한 하트(`gray` #DADADA)는 명암비 1.5:1로 흐리게 보이는 것을 감수한다. 찜한 빨간 하트는 잘 보인다.
- 접힌 행의 긴 제목은 한 줄 말줄임(…)으로 자른다. 모바일에서 한글 15자 정도부터 잘리지만 고려하지 않는다.
- 하트 버튼은 `aria-pressed`로 찜 여부를, 상세보기 버튼은 `aria-expanded`로 펼침 여부를 알린다. 클릭 영역은 작은 하트 32×32, 큰 하트 40×40.

## 결과
- 모바일에서 펼친 행이 길다(375px에서 약 800px).
