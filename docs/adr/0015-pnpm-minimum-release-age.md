# 0015. 갓 배포된 패키지 버전은 설치하지 않는다 (pnpm 최소 배포 기간)

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 1 이후 전체

## 배경
pnpm 12는 배포된 지 24시간(`minimumReleaseAge` 1440분)이 지나지 않은 버전을 기본으로 설치하지 않는다. 계정 탈취 등으로 악성 버전이 올라와도 보통 하루 안에 발견·삭제되므로, 그 기간을 피하는 공급망 보안 장치다.
Step 1에서 `vite@^8.4.0`을 직접 지정하자, 배포된 지 약 18시간 된 버전이라 pnpm이 `pnpm-workspace.yaml`에 예외(`minimumReleaseAgeExclude`)를 자동으로 추가했다.

## 선택지
- A안 예외 없이 규칙을 따름: 직전 안정 버전(vite 8.3.8, 배포 16일 경과)을 쓴다 / 최신 기능·수정이 하루 이상 늦게 들어옴
- B안 예외 등록: 최신 버전을 바로 씀 / 보호 장치를 직접 끄는 것이고, 예외 목록을 계속 관리해야 함

## 결정
A안. 예외를 지우고 vite 8.3.8을 설치했다.
이후 의존성은 버전을 직접 지정하지 않고 `pnpm add <이름>`으로 추가해, 규칙을 통과하는 버전을 pnpm이 고르게 한다.

## 결과
- 저장소에 `pnpm-workspace.yaml` 예외 목록이 없다. `pnpm install`이 lockfile의 공급망 규칙 검사를 통과한다.
- 새 버전이 필요하면 배포 후 하루가 지나 다시 올린다.
