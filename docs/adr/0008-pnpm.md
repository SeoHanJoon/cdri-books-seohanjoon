# 0008. 패키지 매니저는 pnpm, 런타임은 Node.js 26 LTS로 고정한다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 1

## 배경
평가자가 저장소를 받아 실행할 때 의존성 버전과 실행 환경이 개발 환경과 같아야 한다.

## 선택지
- A안 pnpm: 설치가 빠르고 디스크를 적게 씀, 선언하지 않은 패키지를 import하면 에러가 나서 의존성 누락을 일찍 발견 / 평가자 PC에 pnpm이 없으면 설치 필요
- B안 npm: Node.js에 기본 포함 / 설치가 상대적으로 느림, 숨은 의존성을 잡아주지 않음

## 결정
A안. pnpm 12와 Node.js 26 LTS를 쓴다.
`package.json`의 `packageManager`로 pnpm 버전을, `.nvmrc`(`26.13.1`)로 Node 버전을 고정하고 `engines.node`(`>=26`)로 최소 버전을 안내한다.

## 결과
- `corepack enable` 후 `pnpm install`이면 같은 버전의 pnpm으로 설치된다. README 실행 방법에 적는다.
- Node 26 미만 환경에서는 실행 전에 안내 메시지가 나온다.
