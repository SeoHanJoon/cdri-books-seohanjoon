# 0044. 로딩은 스켈레톤, 에러는 안내 문구와 다시 시도 버튼으로 보여준다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 5

## 배경
Figma에는 초기·결과·결과 없음 화면만 있고, 로딩과 에러 화면은 없다. (지원자 판단)
첫 검색, 새 검색, 다음 페이지 불러오기 세 경우의 기다림과 실패를 보여줘야 한다.

## 선택지
- A안 스켈레톤 + 다시 시도: 접힌 책 행 모양의 회색 막대가 결과 자리를 미리 채워 화면이 덜 흔들림 / 만들 것이 조금 많음
- B안 문구 + 다시 시도: 가장 단순 / 로딩 문구와 결과가 번갈아 나와 레이아웃이 크게 바뀜
- C안 이전 결과를 흐리게 유지: 화면이 튀지 않음 / 잠깐 다른 검색의 결과가 보이고, 첫 검색은 따로 처리해야 함

## 결정
A안. (사용자 선택)
- 첫 검색·새 검색: 결과 목록 자리에 스켈레톤 행. 색은 기존 토큰(`light-gray`)만 쓴다.
- 다음 페이지: 목록 아래에 스켈레톤 행 하나.
- 첫 페이지 실패: 목록 자리에 안내 문구와 "다시 시도" 버튼.
- 다음 페이지 실패: 불러온 목록은 그대로 두고 아래에 안내 문구와 "다시 시도" 버튼.

## 결과
- 로딩 중에도 결과 자리의 모양이 유지된다.
- 다음 페이지가 실패해도 이미 본 책을 잃지 않는다.
- 스켈레톤은 화면에만 보이는 장식이라 스크린리더에는 "불러오는 중" 상태로 따로 알린다.
