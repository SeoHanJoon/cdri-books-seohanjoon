# 0047. 새 검색을 불러오는 동안 직전 건수를 그대로 보여준다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 5

## 배경
새 검색을 불러오는 동안 목록 자리는 스켈레톤이다. ([0044](0044-loading-error-ui.md)) 그 위 "도서 검색 결과 총 N건"의 숫자는 아직 모른다. Figma에는 이 상태가 없다.

## 선택지
- A안 숫자 자리만 스켈레톤: 틀린 숫자가 보이지 않음 / `SearchCountText`의 `count`가 `number | null`로 넓어짐
- B안 "총 0건": props 그대로 / 결과가 없다는 뜻으로 잘못 읽힐 수 있음
- C안 직전 건수 유지: props 그대로, 숫자가 깜빡이지 않음 / 잠깐 다른 검색의 숫자가 보임

## 결정
C안. (사용자 선택)
- 첫 화면은 직전 값이 없으므로 0건이다.
- 첫 page가 실패하면 0건으로 바꾼다. 실패 안내 옆에 다른 검색의 숫자가 남지 않게 하기 위해서다.

## 결과
- 검색할 때마다 숫자가 0으로 떨어졌다 다시 올라가는 깜빡임이 없다.
- 직전에 보여준 값은 페이지가 기억한다. 화면에 그린 값만 기억하므로 초기 화면(0건)을 거쳐 검색하면 0건에서 시작한다.
