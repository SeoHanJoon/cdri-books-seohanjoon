# 0039. 화면 단계의 찜 페이지는 fixture 목록만 보여준다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 4, Step 8

## 배경
화면 단계(Step 4)는 저장 기능 없이 fixture로 화면을 만든다. ([0009](0009-screens-first-msw.md))
도서 검색 페이지는 검색어로 세 상태를 오갔지만([0030](0030-fixture-real-response.md)), 찜 페이지에는 입력이 없어 목록 상태와 빈 상태("찜한 책이 없습니다.")를 바꿀 방법이 없다.

## 선택지
- A안 개발용 쿼리로 전환(`?fixture=empty`): 두 상태를 페이지·PR 영상·테스트에서 모두 확인 / Step 8에서 지울 임시 코드가 생김
- B안 목록만 고정: 코드가 가장 단순 / 빈 상태를 Step 8 전까지 페이지에서 볼 수 없음
- C안 빈 상태만 고정: 단순 / `BookList` 재사용을 Step 4에서 확인 못 함

## 결정
B안. (사용자 선택)
페이지는 검색 fixture("무라카미 하루키" 10권)를 찜 목록처럼 보여준다. 빈 상태 분기(`NoData`)는 코드에 넣어 두고, 화면 확인과 테스트는 찜 store가 생기는 Step 8에서 한다.

## 결과
- 화면 단계에만 쓰는 전환 코드가 없다.
- Step 4 PR 영상과 브라우저 테스트에는 찜 페이지의 빈 상태가 없다. 같은 `NoData` 컴포넌트는 도서 검색 페이지와 `/dev/elements`에서 이미 확인했다.
- 건수는 fixture 10권 기준 "총 10건"이다. 시안의 "총 21건"은 Step 8에서 실제 찜 수로 바뀐다.
