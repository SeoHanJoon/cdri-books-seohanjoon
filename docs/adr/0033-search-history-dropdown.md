# 0033. 검색 기록 드롭다운은 SearchBox 안에 둔다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 3, Step 6

## 배경
시안(`757:958`)에서 검색 기록은 입력창 배경이 아래로 늘어나 기록을 감싸는 하나의 상자다(480×153, radius 24).
언제 열고 닫는지, 키보드로 어떻게 움직이는지는 시안에 없다.

## 선택지
- A안 `SearchBox`에 `history`, `onHistorySelect`, `onHistoryRemove` props 추가: 시안처럼 한 상자로 그리기 쉬움 / SearchBox props 증가
- B안 별도 `SearchHistory` 컴포넌트: 역할 분리 / 배경을 이어 그리려면 두 컴포넌트가 서로의 모양을 알아야 함

## 결정
A안. (사용자 선택) 저장 로직은 Step 6에서 페이지가 연결한다.
열고 닫는 규칙 (시안 미명시)
- 기록이 있고 입력창에 포커스가 있을 때 연다.
- Esc, 포커스가 SearchBox 밖으로 나감, 항목 선택, 검색 제출 때 닫는다.
- 키보드는 Tab으로 항목과 X 버튼 사이를 이동한다.

## 결과
- 검색 기록이 0개면 상자가 늘어나지 않는다.
- 방향키로 항목을 고르는 combobox 방식은 코드가 늘어 Step 9 접근성 작업에서 검토한다.
