# 0063. README 구성: 과제 양식 다섯 항목, 대표 판단 + 표, 스크린샷

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 10

## 배경
README는 평가자가 가장 먼저 읽는 문서다. 과제가 정한 항목은 다섯 개(프로젝트 개요, 실행 방법 및 환경 설정, 폴더 구조 및 주요 코드 설명, 라이브러리 선택 이유, 강조하고 싶은 기능)다. 근거 자료로 ADR 62개와 Step PR 9개가 있다. 디자인에 없어서 직접 판단한 동작도 10개가 넘는다.

## 선택지
- 구성: A안 한 파일에 요약하고 근거는 링크로 / B안 README는 짧게, 나머지는 docs/로 나눔 / C안 근거까지 README에 모두 씀
- 강조 기능: A안 대표 5~6개는 문단으로, 나머지는 표로 / B안 전부 표로 / C안 대표 3~4개만
- 화면 자료: A안 스크린샷 + PR 영상 링크 / B안 PR 영상 링크만 / C안 GIF

## 결정
- 과제 양식의 다섯 항목을 그대로 섹션으로 둔다. ADR은 모두 연결하지 않고, 판단 과정이 잘 보이는 몇 곳에만 단다. (사용자 지정)
- 강조 기능은 대표 판단 5~6개를 "왜"까지 쓰고, 나머지 미명시 판단은 한 줄씩 표로 정리한다.
- 스크린샷은 MSW 고정 데이터로 Playwright에서 찍어 `docs/images/`에 둔다. 동작은 Step PR의 영상으로 연결한다.
- 작업 방식(Step 브랜치·PR, ADR, Claude Code 설정)은 따로 섹션을 만들지 않고 "프로젝트 개요" 안에 짧게 쓴다.

## 결과
- 과제 양식과 섹션 이름이 같아 평가자가 항목을 바로 찾는다. 링크가 적어 README만 읽어도 흐름이 끊기지 않는다.
- 스크린샷은 화면이 바뀌면 다시 찍어야 한다. 제출 직전 단계라 바뀔 일은 적다.
