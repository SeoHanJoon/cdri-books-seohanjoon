# 0031. Book.isbn에는 13자리 ISBN 하나를 넣는다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 3, Step 8

## 배경
카카오 `isbn`은 `"8937437562 9788937437564"`처럼 10자리와 13자리를 공백으로 이은 문자열이고, 한쪽만 있거나 빈 문자열일 때도 있다.
화면용 `Book.isbn`([0019](0019-book-view-type.md))은 행 펼침·찜에서 책을 구별하는 키로 쓰인다.

## 선택지
- A안 13자리 → 10자리 → `url` 순서로 하나만: 이름대로 ISBN 값 하나, 키가 비지 않음 / 고르는 코드 필요
- B안 원본 문자열 그대로, 비면 `url`: 코드가 짧음 / 필드에 값 두 개가 섞임

## 결정
A안. (사용자 선택) ISBN은 책을 구별하는 일련번호이므로 한 값만 담는다.
13자리(현재 표준)를 우선하고, 없으면 10자리, 둘 다 없으면 책마다 다른 `url`을 쓴다.

## 결과
- 같은 책이면 검색 결과와 찜 스냅샷의 `isbn`이 같아 비교가 단순하다.
- 고르는 규칙은 변환 함수에 있고 단위 테스트로 지킨다. fixture의 책은 서로 다른 isbn을 가진다.
