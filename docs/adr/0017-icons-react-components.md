# 0017. 아이콘은 Figma에서 SVG로 내보내 React 컴포넌트로 쓴다

- 상태: 채택
- 날짜: 2026-11-27
- 관련 Step: Step 2

## 배경
아이콘은 7개다: 검색, 화살표, 닫기, 작은 하트 2종(16px), 큰 하트 line/fill(24px).
Figma REST API가 요청 한도를 넘어 약 4.5일 동안 막혔고(429), 그 전에 하트 line 1개만 받았다.
NoData 책 아이콘은 비트맵이라 PNG@2x(160×160, 17KB)를 쓴다. ([PLAN](../PLAN.md) Step 2)

## 선택지
- 확보 방법
  - A안 Figma에서 직접 "Copy as SVG"로 내보냄: 시안과 정확히 같음 / 수작업
  - B안 실측 크기·색에 맞춰 직접 작성: 바로 진행 가능 / 모양이 시안과 다를 수 있음
- 사용 방식
  - A안 React 컴포넌트로 옮기고 색은 `currentColor`: 토큰 색 클래스로 색을 바꿈, 의존성 없음 / SVG를 코드로 옮기는 수작업
  - B안 `vite-plugin-svgr`로 `.svg` 파일 import: 원본 파일 유지 / 라이브러리 추가

## 결정
확보는 A안(직접 내보냄), 사용은 A안(React 컴포넌트).
아이콘이 7개뿐이라 플러그인을 들일 이유가 적다. `currentColor`로 두면 `text-red` 같은 토큰 클래스로 색을 정해, 색 기준이 `@theme` 한 곳으로 유지된다.

## 결과
- 아이콘 색도 디자인 토큰 규칙 안에 들어온다.
- Figma에서 아이콘이 바뀌면 SVG를 다시 옮겨야 한다.
